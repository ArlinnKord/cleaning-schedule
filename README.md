# Cleaning Schedule — Отель БРИДЖ

Автоматизация составления расписания уборок для горничных из программы Эдельвейс.

---

## Варианты скриптов

В репозитории 3 версии, каждая в своей папке:

| Папка | Что делает |
|---|---|
| `отчёты_горничным_без_сортировки/` | Выгружает уборки из Эдельвейс в XLSX. Номера не сортирует. |
| `отчёты_горничным_с_сортировкой/` | То же самое, но номера отсортированы по возрастанию. |
| `разбивка_по_горничным/` | Распределяет уборки между конкретными горничными с учётом нагрузки (генерирует отдельные листы на каждую горничную). |

`archive/` — старые версии скриптов, сохранённые для истории.

---

## Как установить на новом компьютере

### 1. Установить Node.js

Скачай и установи с [nodejs.org](https://nodejs.org) (версию LTS).

### 2. Скачать репозиторий

Открой терминал (cmd) и выполни:

```bash
git clone https://github.com/ArlinnKord/cleaning-schedule.git
cd cleaning-schedule
npm install
```

Готово. Можно пользоваться `.bat`-файлами в каждой папке.

### Если Git не установлен

Скачай [Git для Windows](https://git-scm.com/download/win) и установи, либо нажми на GitHub зелёную кнопку **Code → Download ZIP**, распакуй и выполни `npm install` в распакованной папке.

---

## Как пользоваться (для любой из версий)

1. В программе Эдельвейс открой отчёт «ЗАЕЗДЫ/ПРОЖ./ВЫЕЗДЫ» и выгрузи его.
2. Сохрани файл в папку `отчёты_из_эдельвейса` (название — дата, например `09.07.xls`, обязательно `.xls`, не `.xlsx`).
3. Дважды щёлкни по `Сформировать_отчёт.bat` (или `Сформировать_листы.bat`).
4. Готовый файл появится в папке `готовые_отчёты`.

Подробная инструкция с картинками лежит в каждой папке — `Инструкция.txt`.

## История версий

- **v1** — `archive/`: первые скрипты (график-уборок, виды-уборок, отчёт-горничным)
- **v2** — `отчёты_горничным_*`: автозагрузка из Эдельвейс, генерация XLSX
- **v3** — `разбивка_по_горничным/`: распределение задач с балансировкой нагрузки
