КАК ЗАПУСТИТЬ ГРАФИК УБОРОК
=================================

Каждый день делай 3 шага:

ШАГ 1. ВЫГРУЗКА ИЗ ЭДЕЛЬВЕЙС
- Открой отчёт "Заезды/Выезды/Проживания" в Эдельвейс
- Сохрани как .xls файл в папку:
  отчёты_из_эдельвейса\ДД.ММ.xls
  Пример: отчёты_из_эдельвейса\03.07.xls

ШАГ 2. ЗАПУСК СКРИПТА
- Нажми Win+R, напиши cmd, нажми Enter
- В чёрном окне напиши и нажми Enter:
  cd C:\Users\Администратор\cleaning-schedule
  node график-уборок.js

ШАГ 3. ЗАБЕРИ ОТЧЁТ
- Готовый файл появится в папке:
  готовые_отчёты_уборка\график-уборок-ДД.ММ.ГГ.xlsx

В ОТЧЁТЕ 7 ЛИСТОВ:
- Уборки на сегодня     — общий график всех номеров
- По горничным          — сгруппировано с итогами
- Сводка                — статистика по нагрузке
- Карточки заездов      — комната, гости, ночей, даты (для ключей)
- Горничная 1 / 2 / 3   — все номера, но раскрашены только её уборки

ВАЖНО:
- Файл в отчёты_из_эдельвейса должен быть именно .xls (не .xlsx)
- Называй по дате: 03.07.xls, 04.07.xls и т.д.
- Скрипт сам определяет сегодняшнюю дату
- Если файла на сегодня нет — возьмёт первый попавшийся
